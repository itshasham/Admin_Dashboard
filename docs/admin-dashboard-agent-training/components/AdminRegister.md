# AdminRegister

Source: `frontend/M3/src/pages/AdminRegister.jsx`

Route: `/admin/register`

Purpose:

- Registers an admin/staff account.

Endpoint:

- `POST /admin/register`

State:

- `formData`
- `loading`
- `error`
- `success`

Behavior:

- Validates password confirmation locally.
- Shows success message.
- Navigates to login after successful registration.
