- `GET /cloudinary/images`
- `POST /cloudinary/add-img`
- `POST /cloudinary/add-multiple-img`

- `singleFile`
- `multiFiles`
- `uploading`
- `errorTitle`
- `errorDetails`
- `images`
- `query`
- `role`
